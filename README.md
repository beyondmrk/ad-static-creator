# ad-localize

A Claude Code skill that localizes and adapts competitor ads for your product and market.
Each ad is recreated **1:1** (the same layout, people, colours and typography), changed
only where it is wrong for you:
- the on-image text, made native in the target language;
- the competitor's product and name, replaced with yours;
- prices, currency, offers and guarantees, replaced with yours;
- flags and country references, changed to your market.

Team rules such as "12 ads a day, 4 provided, the rest researched at 10,000+ reach" live in
a **profile** (`profiles/daily-12.json` is an example), and the script enforces them.

The agent reads and translates the text itself; no localizer app is involved. Images are
recreated in **Google Flow** (Nano Banana 2) through the [flow-mcp](https://github.com/beyondmrk/flow-mcp)
bridge. A script, `adloc.py`, assembles every generation prompt from a structured file and
refuses to move on when something is missing or wrong.

## How a job runs

1. **init**: create the job folder with the brief: product, language, market, and our
   price, currency, offer and guarantee.
2. **fetch**: download the competitor creatives from their Meta Ad Library links, and
   record each one's link, origin (provided or researched), reach and niche note.
3. **scan**: check the profile's set rules, drop duplicates (perceptual hash), and pick
   each ad's Flow aspect ratio.
4. **localize**: the agent fills `ads.json`: a scene description; every text block with
   its original, its target and its kind (copy, brand, price, offer, guarantee or
   country); and any visual swaps, such as flags.
5. **build**: `adloc.py` validates everything and assembles the Flow prompts. It refuses:
   - unfilled fields;
   - a competitor name left in;
   - a price or offer containing numbers that aren't in our brief;
   - offer-looking text filed as plain copy;
   - a product swap with no product image;
   - a set that breaks the profile.
6. **Flow**: the agent fires one still per ad through flow-mcp.
7. **finish**: crop back to the original aspect, then OCR-check the text. It flags misspelt
   or missing words, a leftover competitor name, and text that appeared on an ad that had
   none.
8. **deliver**: name the files with the profile's pattern, strip all metadata, verify it,
   and optionally upload with rclone (never overwriting). Any ad that failed the text check
   is refused unless the user accepts it. It also prints the status-sheet line and a draft
   team message for the user to send.
9. **feedback**: the reviewer's fixes are re-delivered with `--only NN --suffix v2`.

The agent stops for the user's OK before downloading and again after the results, and
never re-rolls without being asked. `SKILL.md` has the full checklist.

## Requirements

| Requirement | What it's for | Required? |
|---|---|---|
| [Claude Code](https://claude.com/claude-code) | Runs the skill | yes |
| [flow-mcp](https://github.com/beyondmrk/flow-mcp), plus a Google Flow account | Image recreation. Flow stills cost 0 credits on Google AI Ultra; other plans may differ | yes |
| Python 3.9+ with `pip install -r requirements.txt` | Pillow and RapidOCR, for building, cropping and the text check | yes |
| A browser tool for the agent | Reading Meta Ad Library pages. Without one, save the images into `01_originals/` by hand | no |
| ffmpeg | Video ads, and stripping metadata from mp4 files | video only |
| faster-whisper, edge-tts, demucs | The video recipe | video only |
| rclone | Uploading the delivery | no |

## Install

1. Install and configure flow-mcp (see its README). Note its `work_root`: every job folder
   must sit inside it.
2. Copy this folder to `~/.claude/skills/ad-localize/` (or to a project's `.claude/skills/`).
3. Run `pip install -r requirements.txt`.
4. Optional: set `FLOW_WORK_ROOT` to the same folder as flow-mcp's `work_root`. `init` then
   refuses a job folder the bridge would reject.

Then ask Claude Code something like *"localize these 5 competitor ads into German for our
product"* and paste the Ad Library links.

## Known limits

- **Aspect ratios.** Flow offers 1:1, 3:4, 4:3, 9:16 and 16:9 only. Any other ratio (such
  as 4:5) is padded to the nearest one and cropped back. This method is **experimental**,
  so compare every padded ad's crop with its original.
- **Special characters.** The OCR check ignores accents (ö reads as o), so check special
  characters by eye.
- **Ad Library images** come at no more than 600 px on the long side, so that is the
  reference resolution.
- **Text in the image is generated by the model.** Re-roll misspellings: `build --spell NN`
  spells the words out letter by letter in the prompt.
